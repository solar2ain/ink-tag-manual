01

一块屏幕，不止一种用途

从一张安静的照片，到每天更新的信息。设备负责显示，WebUI 负责创作；需要外部数据时，再让电脑接手。

A.

日历与时钟

使用设备原生页面，设置好后由设备计时和更新。时钟刷新更频繁，选用前留意耗电提示。

B.

图片与信息牌

照片、二维码、待办、文字卡片，在画板里排版，转成屏幕支持的颜色后发送。

C.

天气站与日期牌

由在线电脑获取天气并渲染，再定时通过蓝牙推送。关闭浏览器不影响已运行的 CLI 任务。

多平台，共用一套客户端

适配工作覆盖深圳市汇顶科技股份有限公司（Goodix）的 GR5331 / GR5513 / GR5515、昂瑞微电子（OnMicro）OM6626、泰凌微电子（Telink）TLSR8359，以及 Nordic 系列。具体固件开放范围以项目清单为准。

先核对硬件，再选择配置

同一款价签可能更换主控或屏幕；HS9118 是封装丝印，不等于唯一的实际主控。不要仅凭外壳型号或屏幕尺寸选择镜像、引脚或驱动。

墨水屏不是液晶屏。它借助环境光显示，没有持续背光。刷新通常需要几秒至十几秒，也可能闪烁；多色屏、低温时会更慢。保留静态画面不等于整机零耗电，蓝牙、计时和刷新仍会消耗电量。
02

三步，显示第一张图片

你需要：已安装兼容固件的设备、稳定供电，以及能访问蓝牙的客户端。

  1. 打开 WebUI，点击「连接」

    推荐在支持 Web Bluetooth 的 Chrome / Edge 中使用 HTTPS 或本机站点。iPhone / iPad 的常见浏览器通常不能直接使用 Web Bluetooth；也可改用电脑 CLI。

  2. 在「设置」核对设备和屏幕

    读取主控、固件版本、屏幕尺寸、颜色和方向。已有正常配置不必重新填写。无法读取或不确定引脚时，不要猜测后保存。

  3. 在「图片」或「创作」中发送

    导入图片或选择模板，先查看设备效果。默认「仅显示一次」；需要保存时再选择图槽和图片名。传输到 100% 后仍要等待屏幕刷新结束。

扫码连接不是跳过授权。设备二维码或 NFC 链接可带入准确蓝牙名；浏览器已授权时会尝试重连，否则需要点击选择设备。启用了设备密码时，仍须正常认证。
在线 WebUI ↗本地使用方式 ↓在线站点可用性以项目开放状态为准
03

把照片，变成墨水屏的颜色

屏幕只有固定的几种颜料，不能像手机一样混合出任意颜色。图片处理，就是在有限色板和像素之间做选择。

黑白

文字、线稿与高对比照片

黑白红

红色作为日期、重点信息

黑白红黄

适合信息分组与醒目标记

六色

更丰富的配色，仍非全彩

照片：保留轮廓和层次

  • 先裁剪主体，再调整方向和亮度。
  • 试用抖动算法，并适当降低抖动强度；不是强度越大越好。
  • 红花、衣服等可保留强调色；避免把所有暗部都变成红色。

文字：清晰比细节更重要

  • 文字和线稿通常不需要抖动。
  • 采用黑色正文、少量强调色，避免浅灰小字。
  • 按屏幕实际像素看效果，不要只看放大的编辑画布。

预览的浅灰底用于模拟电子纸，不会把整张图片涂成灰色。具体色彩、对比度和残影因面板、温度与刷新方式而异，预览不能代替实屏效果。

04

在画板里，安排每一块信息

先选尺寸和用途，再放置控件。小屏更适合少量大字，信息不是越多越好。

页面类型谁来渲染和更新字体与联网
静态页面客户端生成一张图片，发送后保留可用浏览器字体；设备不需要安装同款字库
设备动态页面设备原生页面，例如日历、时钟使用设备已有字体和能力；自定义设备动态布局尚未开放
主机动态页面电脑获取数据、渲染和定时推送电脑需开机；天气取数需网络，推送需蓝牙

编辑时

  • 添加文字、图片框、二维码、表格、列表和笔迹。
  • 拖动移动，四角缩放；右侧修改尺寸、配色和内容。
  • 双击图片框选择图片，调整适配方式和抖动参数。
  • 锁定完成的控件，避免误拖；锁定后需先解锁才能删除。

发送前

  • 打开「设备效果预览」，检查文字、颜色和方向。
  • 模板不必先保存成页面，也可直接发送。
  • 默认「仅显示一次」，保存图槽需主动选择。
  • 编辑后离开会提示保存、暂存草稿或放弃；清除网站数据可能同时删除本地草稿。
模板尺寸差一点也能用。普通画板发送会先自动对齐横竖方向，再居中裁切或补白，不拉伸画面。重要文字和二维码请远离边缘，并检查最终预览。主机定时推送采用更严格的尺寸校验，避免无人值守时错发。

底部 InkTag 标识由设备授权决定。Free 保留固定标识；Pro 可调整或隐藏。编辑器里的标识只是预览，不会替代设备端的最终检查。

05

存几张图，让它自己轮播

「仅显示一次」与「保存到图槽」是两件事。保存后，图片才会出现在设备资源列表里。

选择图片裁剪与预览
→
保存到图槽指定名称和位置
→
设置轮播设备自主切换
  1. 发送时选择保存

    使用空闲图槽，或明确替换现有图槽。图片名称在上传 / 替换时写入；不能单独改名。替换中途断电可能丢失目标旧图。

  2. 在资源列表检查

    可显示、下载或删除图片。删除后会留下空位，图槽 ID 不保证连续；以设备返回的列表为准。

  3. 设置轮播间隔

    准备至少两张与当前屏幕匹配的图片，再开启轮播。断开电脑后仍可运行。频繁刷新会增加耗电，建议按实际需要设置。

Free 图槽配额：可视区长边小于 300 像素，最多 10 张；其余最多 4 张。实际可用数量还受图片大小和可用空间限制。Pro 不设商业数量配额，但不会扩大物理存储。独立 Free-only 项目的容量规则以各自说明为准。

06

让天气，自己来到桌面

主机动态页面 = 画板原稿 + 数据源 + 定时任务 + 准确设备。墨水屏不直接运行天气脚本。

  1. 在「创作」选择天气站或日期牌

    选择合适的分辨率，移动控件、调整配色。小屏优先保留日期、天气与大字温度，不要堆入整套大屏信息。

  2. 设置地点、经纬度和时区

    在天气数据源区域获取实际天气预览，核对日期和数值。演示数据只用于排版，不能当作最新天气自动推送。

  3. 导出主机任务，交给 CLI

    导出 *.inktag.json 原稿，导入为 TOML 配置，绑定准确蓝牙地址和设备身份，再显式开启任务。自动推送需要 Pro 和兼容设备。

离线排版检查 · 不连接设备inktag host import weather.inktag.json --config weather.toml
inktag host validate weather.toml
inktag host render --scene weather.inktag.json --demo -o preview.png

获取实际天气并检查图片inktag host fetch weather.toml --output forecast.json
inktag host render --scene weather.inktag.json --snapshot forecast.json -o weather.png

绑定一次，再定时运行

inktag --device 准确蓝牙名 host target 读取目标。将返回的 address 和 expected_device_id 填入任务，并设 enabled = true。名称仅便于辨认，运行时按地址和身份核验。macOS 的地址通常是本机蓝牙 UUID，不是可跨电脑复用的 MAC。

先不推送，再尝试一次

inktag host run weather.toml --once 只生成图片；确认正确后加 --send 推送。去掉 --once 持续运行。电脑需要开机，设备需在蓝牙范围内，具体目标仍需实板验证。

可由 Windows 任务计划程序或用户级定时任务执行 inktag host run /配置绝对路径/weather.toml --once --send。不要同时启动多个相同任务。停止电脑任务或设置 enabled = false 才会停止后续推送；设备上的停止按钮不会关闭电脑任务。

天气源为 Open-Meteo。请求包含配置的地点与天气字段，不附带设备身份、密码或 Find 信息。请遵守天气源条款；接口不可用时会报告失败，不会把演示数据冒充最新数据。中文渲染可指定本机字体文件，字体不随原稿分发。

07

设置，先读回再保存

普通用户不需要记住寄存器或引脚编码。已有配置应先从设备读取，换屏和改线时才调整。

设置位置可以做什么注意事项
显示 / 屏幕 Profile选择屏幕预设、尺寸、颜色和方向控制器相近不等于屏幕可通用；电气时序由驱动处理
板卡查看及保存已支持的屏幕、LED 引脚只使用已确认的接线；扩展按键和蜂鸣器按设备能力提供，未实现项不可写入
激活 / 设备密码安装设备绑定的激活码；设置密码保存好激活码；修改或删除已启用密码需要重新验证原密码
固件检查更新，选择兼容本地包进行 OTA本期不提供固件；只用项目批准的签名兼容包，不能只看版本号更大

时钟与局部刷新

普通连接会尝试校时一次。时钟按分钟更新，即使屏幕支持局部刷新，仍可能每天全刷并切换背景。局刷取决于实际屏幕与固件支持；比起静态图片，时钟更耗电。

换屏之前

先下载需要保留的图片。更改屏幕几何或色板后，旧图可能不再兼容。清屏只是改变画面，并不删除已保存图片；修改 Profile 也不是图片备份。

重启、重置、清数据，不是一回事

操作作用范围
重启设备重新启动运行中的固件，不等于恢复设置
重置设置恢复普通设置并清除设备密码 / 管理二维码；保留设备图片、Pro 与 Find
清除用户数据删除设备图片及其名称引用；保留设置、密码、Pro 与 Find
完整烧录是另一条流程。它会清理并重写主控上的相应内容，不能当作普通重启或日常更新。操作前应明确影响范围并备份；外置存储的处理以准确平台说明为准。本期没有有线烧录包。

Find：用之前，先理解边界

防丢器利用 Apple Find My 网络的附近设备报告位置，不是 GPS 实时定位，也不是 Apple 官方客户端。位置可能延迟或暂时没有报告。需要 Pro、兼容固件及本地 Find 服务；纯静态站点不能独立完成 Apple 登录与查询。

账号与本机数据

建议使用专门注册的 Apple 账号，不用个人常用账号。账号密码和验证码只在本机界面输入。Windows 认证运行依赖、macOS 原生方案的可用状态以客户端说明为准。

备份与隐私

保管好本地身份库、恢复资料及会话数据。它们不在屏幕上，也不应进入公开仓库。遇到登录失败先记录阶段和错误码，不要通过清空身份库来尝试修复。

09

选择适合你的使用方式

只是发张图片，先用 WebUI。需要本地 Find、长期运行或自动化，再安装本地服务或 CLI。

方式适合准备
在线 WebUI直接编辑、连接、传图在线站点开放；支持 Web Bluetooth 的安全浏览器
独立 HTML / 静态包本地使用或自行托管不需要 Node.js；蓝牙仍受浏览器安全上下文限制；不自带 Find 服务
本地服务包固定本机地址、持久数据与 FindPython 3.11+；Find 另需认证运行依赖
Python CLI终端操作、主机任务与脚本Python 3.11+、系统蓝牙与相应权限

本地服务：先安装，再打开

解压本地服务包进入目录。Windows 双击 install.cmd，macOS 运行 install.command，Linux 运行 sh install.sh。按照窗口提示完成依赖安装并访问本机地址。

http://127.0.0.1:8787/

Windows Find 首次安装还需要完整 7-Zip 并下载运行依赖；macOS 原生认证仍待真机验证，Linux Find 登录暂未验证。普通传图不需要登录 Apple。

CLI：不需要开发环境

解压 CLI 包，进入 inktag-cli 目录。可使用包内安装入口，或在自己的 Python 虚拟环境执行：

python -m pip install .
inktag --help
inktag device scan
inktag --device IKT_TL_1234 device info

示例设备名请替换为扫描得到的准确名称。连接同一台设备时，先断开 WebUI，避免多个客户端同时抢占。

手机访问电脑上的服务

在本地服务包目录运行 python start.py --lan。按终端显示的局域网 HTTPS 地址访问，使用用户名 inktag 与本次访问密码登录。手机需连接同一局域网，并信任你自己电脑生成的证书；普通局域网 HTTP 不满足蓝牙要求。即便 HTTPS 正常，手机浏览器本身也必须支持 Web Bluetooth。

保持数据目录固定。Windows 默认位于当前用户的 %LOCALAPPDATA%/InkTag。不要随意删除、放入公开下载目录或同步到公共仓库；不要把带有 Find 数据的本地服务直接暴露到互联网。

几条常用 CLI 命令

已安装 CLI 后使用；设备名为示例inktag --device IKT_TL_1234 screen show
inktag --device IKT_TL_1234 display calendar
inktag --device IKT_TL_1234 image upload photo.jpg --preview preview.png
inktag --device IKT_TL_1234 image upload photo.jpg --slot next --name landscape
inktag --device IKT_TL_1234 slot list
inktag --device IKT_TL_1234 slideshow start --interval 5m
inktag --device IKT_TL_1234 slideshow stop

不带 --slot 的图片上传直接显示；保存与替换需明确选择。命令和参数以安装版本的 --help 为准。走时观察可用 --no-time-sync 避免默认连接校时，日常操作通常不需要。

10

卡住时，先看这里

先检查供电、浏览器、准确目标和当前操作，再考虑修改配置。

蓝牙选择框里没有设备？

确认设备运行兼容 InkTag 固件、供电正常且在附近；系统蓝牙和浏览器蓝牙权限已开启。先断开其他客户端。以实际蓝牙名选择，Recovery 名称通常带 _OTA，不是普通应用。原厂固件不一定能由 InkTag WebUI 管理。

手机能打开网页，为什么不能连接蓝牙？

网页能显示不代表浏览器有 Web Bluetooth。使用支持该功能的浏览器，并从可信 HTTPS 或本机地址打开。普通局域网 HTTP 和未受信任的证书可能导致蓝牙不可用。iOS 的常见浏览器通常不提供该能力，可改用支持的电脑浏览器或 CLI。

进度已经 100%，为什么屏幕还没动完？

100% 通常只是图片字节传完，面板还在执行刷新波形。等待最终完成提示，期间保持供电。刷新时间受屏幕、温度和颜色影响。失败时记录错误信息，不要连续重复点击或凭一次超时判断硬件损坏。

画面反了、被裁切、颜色不对怎么办？

先核对设备实际屏幕预设、方向、颜色与已确认接线，再查看发送预览。普通画板会自动对齐横竖方向后居中裁切 / 补白，尺寸差较大时边缘内容仍可能丢失。不要通过乱改电平或尝试陌生驱动来解决排版问题。

屏幕断电还能保图，为什么时钟不走了？

墨水屏保留的是最后一帧。计时、蓝牙和刷新都需要主控供电。更换电池或掉电后重新连接校时。保图不是整机断电后仍在运行。

天气站停留在旧数据？

检查主机是否开机、任务是否启用、天气取数是否成功，以及推送时设备是否在蓝牙范围内。先运行 host status 查看任务结果。天气页面并不是设备直接联网，关闭电脑后不会继续从网络更新。

图片工具打不开，需要刷新整个网页吗？

先点击页面中的「重试打开图片工具」，不必立即刷新或断开蓝牙。若站点刚更新，重新加载页面可能解决旧资源缓存问题，但会丢失当前蓝牙连接和未保存编辑；先保存原稿或草稿。

设备密码、Pro、服务访问密码有什么区别？

设备密码限制设备操作；Pro 激活码开启绑定设备的进阶能力；局域网服务访问密码保护本机服务入口；Apple 账号用于 Find 查询。它们不能互相替代，也都不应放进公开反馈。

Apple 登录报错，应该改密码还是清数据？

不要把所有认证失败都当成密码错误。记录安全可展示的错误码、发生阶段和客户端版本，检查本机时间与网络后反馈。不要公开密码、验证码或完整认证日志，也不要删除 Find 身份库来重试登录。

怎么反馈问题，才容易定位？

附上客户端版本、主控、屏幕预设、操作步骤及可安全展示的错误提示；画面问题可拍清晰屏幕照片。遮住真实账号、激活码、设备密码、二维码控制凭据和定位信息。区分“传输失败”与“传完但显示错误”。
